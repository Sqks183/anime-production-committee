# 经济模拟器使用说明

这是一个独立于游戏 C++/WASM 运行时的 Python 蒙特卡洛模型，用于复用现金流口径、比较承制/委员会路线，并测试延期压力与违约扣罚。它不是游戏内核，也不代表所有 V1 机制已经实现。

## 运行

Python 3.10+，无第三方依赖。在仓库根目录执行：

```bash
python scripts/economic_simulator.py
python scripts/economic_simulator.py --config scripts/simulation_config.example.json --out build/economic-sim
python scripts/run_sensitivity.py
python -m unittest discover -s scripts/tests -v
```

模拟器输出 `summary.json` 和逐次结果 `trials.csv`；敏感性脚本输出 `simulation-sensitivity/sensitivity.csv/json`。相同代码、配置和 seed 可复现相同结果。

## 当前模型口径

- 经营周期520周，初始现金5000万日元，每次市场刷新生成4个候选企划；简化策略从开工前现金可负担的候选中随机选择。
- 承制不支付投资；委员会公司投资额 = 合同预算 × 2 × 玩家投资比例。资格检查使用拨款前现金。接约时先扣投资，再将合同预算一次性加入公司现金池；其他投资方资金不进入公司现金。
- 项目期间按周扣正常固定运营成本。可选 `production_cost_ratio` 是项目制作/外包成本占位旋钮，默认0，不沿用此前被否定的预算65%直接制作成本。
- 正常或低完成度交付才结算BD收入。违约不结算商业收入；委员会投资本金已在开工时支付，不重复扣除；合同违约处罚单独按预算比例扣现金。
- 承制不延期。委员会项目如超过原合同周期，自动使用一次20%延期；压力按实际超出原合同周期的周数逐周累积，并按配置阈值扣声望。
- 承制成功奖励按暂定商业分数门槛和预算比例计算。非BD渠道收入公式尚未定，默认关闭，可通过配置打开实验。

## 重要限制

1. 制作完成时间目前是占位模型。真实五阶段动态工作量、人员产能、临时员工与外包统一模型尚未接入，当前用可配置对数正态工期分布模拟相对合同周期的快慢。这不能代替真实制作进度模拟。
2. 默认每周固定运营成本68万来自早期讨论的暂定基准，需要与最终员工工资、固定运营费契约对齐。
3. 商业分数采用暂定模型B权重（受众50%、热度20%、质量20%、匹配10%）和可配置随机波动；项目类型/规模不直接提高商业分数。商业分数与项目完成度暂时独立。
4. 普通作品声望变化、声望对市场机会的反馈、市场热度变化、招聘/成长/疲劳/士气、事件、原创开发、电视服务、渠道适配与前作IP收益尚未接入。
5. 当前四类企划使用单一标准预算/周期，尚未实现每种类型的小/中/大规模梯度；工作量字段未用于计算产能，动态阶段合格线也未实现。
6. 违约处罚、最低可交付完成度、压力增长和声望惩罚仅是实验变量，不是正式规则数值。默认值只为跑通模型，不代表推荐定案。

结果适合做敏感性分析、检查资金流重复扣除/遗漏、观察延期和违约参数的方向性影响。不能单独证明经济系统已经平衡；接入阶段工作量和人员产能模型后必须重新校准。
