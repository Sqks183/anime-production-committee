# M4 商业结算手算 Fixture（集成对账用）

> 状态：集成验证样例，不是数值平衡基准
> 日期：2026-11-26
> 依据：DEC-COMM-001/002/003、DEC-BD-001、DEC-ECON-001、DOMAIN_ARCHITECTURE §10.6
> 用途：验证投资本金、制作费、实际制作成本、BD 收入与非 BD 委员会商业分配彼此独立。
>
> 本文金额均为人为构造的整数输入，只用于验证账务口径；不代表收入预测、费率、渠道权重或平衡参数。未在样例中出现的费用/倍率不代表规则不存在。

## 1. 固定输入

### 1.1 项目与投资

| 项目 | 输入 |
|---|---:|
| 制作费 / 合同预算 | 1,000 |
| 委员会总投资池 | 2,000 |
| 玩家投资比例（样例 A） | 30% |
| 玩家初始投资本金（样例 A） | 600 |
| 实际制作成本 | 1,100 |
| 制作毛利 | -100 |

由 DEC-COMM-003：

- 委员会总投资池 = 制作费 × 2 = 2,000。
- 制作费是制作公司的收入；实际制作成本是制作公司的费用。
- 玩家初始投资本金 = 2,000 × 30% = 600。
- 制作毛利 = 1,000 - 1,100 = -100。
- 投资本金不是制作收入，不能用制作毛利替代投资损益。

### 1.2 商业渠道输入

假设本项目为委员会项目，以下渠道均已按规则开放：

- 国内配信：由对应委员会成员开放。
- 海外发行：由对应委员会成员开放。
- 玩具/周边：由对应委员会成员开放。
- 音乐：由对应委员会成员开放。
- 电视版权：本样例关闭，收入为 0。
- BD/DVD：基础渠道，无需委员会成员。

假设未购买电视服务、没有电视台成员提供播出，因此本样例不应用电视曝光倍率。下表是已经完成渠道适用系数计算后的毛收入输入，不再从潜力/质量/热度等上游变量反推。

| 渠道 | 毛收入 | 归属/处理 |
|---|---:|---|
| 国内配信 | 230 | 进入委员会商业池 |
| 海外发行 | 160 | 进入委员会商业池 |
| 玩具/周边 | 92 | 进入委员会商业池 |
| 音乐 | 46 | 进入委员会商业池 |
| 电视版权 | 0 | 关闭，无收入 |
| BD/DVD | 92 | 始终归制作公司；公司取得 50% |
| **非 BD 毛收入合计** | **528** | 委员会项目商业池的计算起点 |
| **全部窗口毛收入** | **620** | 仅用于展示，不作为单一分账池 |

另设适用且已约定的前置商业成本为 28。它是本 fixture 的输入，不代表新增费用类别或默认收费。

## 2. 样例 A：委员会项目，玩家投资 30%

### 2.1 非 BD 委员会商业池

| 步骤 | 算式 | 结果 |
|---|---|---:|
| 非 BD 毛收入 | 230 + 160 + 92 + 46 + 0 | 528 |
| 扣除适用前置商业成本 | 528 - 28 | 500 |
| 玩家商业分配 | 500 × 30% | 150 |
| 其他委员会成员分配合计 | 500 × 70% | 350 |
| 分配总额核对 | 150 + 350 | 500 |

**关键结论：** 分配基数是扣除适用前置商业成本后的 500，不是毛收入 528。所有成员按同一投资比例分享净商业池，不采用本金优先返还。

### 2.2 BD/DVD

| 项目 | 算式 | 结果 |
|---|---|---:|
| BD/DVD 毛收入 | 输入 | 92 |
| 制作公司所得 | 92 × 50% | 46 |
| 综合成本部分 | 92 × 50% | 46 |

BD/DVD 的 46 公司所得不进入委员会商业池，也不按 30% 投资比例分配。综合成本部分已经包含在 BD 的 50/50 规则中，不得再重复扣一次现金或制作成本。

### 2.3 两本账分别核对

| 账务视角 | 算式 | 结果 |
|---|---|---:|
| 制作经营毛利 | 制作费 1,000 - 实际制作成本 1,100 | -100 |
| 投资损益 | 累计商业分配 150 - 初始投资本金 600 | -450 |
| BD 公司所得 | 92 × 50% | +46 |

三者是不同事实：

- 制作经营毛利衡量制作公司是否以制作费覆盖实际制作成本。
- 投资损益衡量玩家作为投资方获得的商业分配相对投入本金的结果。
- BD 公司所得归制作公司，不进入委员会商业池，也不计入投资方商业分配。

不得将 -100、-450 和 +46 合并成一个“项目利润”字段。

## 3. 样例 B：同一项目输入，玩家投资 100%

除玩家投资比例外，其他输入与样例 A 完全相同。

| 项目 | 算式 | 结果 |
|---|---|---:|
| 初始投资本金 | 2,000 × 100% | 2,000 |
| 非 BD 净商业池 | 与样例 A 相同 | 500 |
| 玩家商业分配 | 500 × 100% | 500 |
| 其他成员商业分配 | 500 × 0% | 0 |
| 投资损益 | 500 - 2,000 | -1,500 |
| 制作毛利 | 1,000 - 1,100 | -100 |
| BD 公司所得 | 92 × 50% | +46 |

此例用于确认：

- 100% 投资比例下，玩家取得全部委员会净商业池。
- 不存在先返还本金、再分利润的瀑布式分配。
- 投资损益仍与制作毛利、BD 公司所得分开。

## 4. 样例 C：承制项目

使用同样的制作费、实际制作成本与 BD 毛收入，但合作模式改为承制。

| 项目 | 结果 | 说明 |
|---|---:|---|
| 制作费收入 | +1,000 | 客户支付给制作公司 |
| 实际制作成本 | -1,100 | 制作公司承担 |
| 制作毛利 | -100 | 允许出现制作亏损 |
| 投资本金 | 0 | 承制模式不创建委员会投资池 |
| 委员会商业分配 | 0 | 不创建委员会，不参与非 BD 常规窗口分配 |
| BD/DVD 公司所得 | +46 | BD/DVD 始终归制作公司 |

承制项目不得因为拥有渠道或商业表现而被错误地分配非 BD 委员会商业收入。

## 5. 集成必须保持的恒等式

1. 委员会总投资池 = 制作费 × 2。
2. 玩家初始投资本金 = 委员会总投资池 × 玩家投资比例。
3. 制作毛利 = 制作费收入 - 实际制作成本。
4. 非 BD 净商业池 = 非 BD 毛收入 - 适用且已约定的前置商业成本。
5. 委员会各成员商业分配之和 = 非 BD 净商业池。
6. 玩家投资损益 = 玩家累计商业分配 - 玩家初始投资本金。
7. BD 公司所得 = BD/DVD 毛收入 × 50%；其余 50% 为综合成本，不重复扣账。
8. 承制模式的委员会投资本金、委员会非 BD 商业分配均为 0。
9. 任何一笔实际现金变化只进入 Finance 一次；项目账仅做归因，不得形成第二个现金池。

## 6. 实现前需要核对的接口口径

- **分配基数：** DEC-COMM-003 是权威决策；DOMAIN_ARCHITECTURE §10.6 已在本 PR 同步为同一完整口径：先汇总非 BD 渠道毛收入，扣除适用且已约定的前置商业成本，得到净商业池，再按投资比例 Pro-rata 分配。
- **渠道开放：** 委员会对应成员开放时手续费为 0%；无成员时，需满足合作历史或声望门槛才可外部代理软绑定；否则渠道关闭、收入为 0。代理费率与声望门槛仍属待标定参数。
- **电视曝光：** 电视倍率只作用于国内配信、玩具/周边、音乐和 BD/DVD；不作用于海外发行与电视版权收入。本 fixture 未启用电视曝光，避免把倍率与分账问题混在同一验算中。
- **Finance 类别：** 实际流水类别必须复用当前 Finance 已批准枚举。本文不新造 category 名称；若现有枚举无法表达上述事实，应先提交契约差异，不得在模块内私自新增。
- **舍入：** 本 fixture 使用整数输入与整除结果，不裁定通用比例分配的余数归属规则；若运行时出现非整除金额，必须沿用已冻结的整数舍入契约，不能在各模块分别舍入。

## 7. 最小验收用例

不扩展为大规模排列组合，仅保留：

1. 样例 A：30% 投资，前置成本先扣，净池按比例分配。
2. 样例 B：100% 投资，玩家获得全部净池，不发生本金优先返还。
3. 样例 C：承制项目只有制作费/制作成本与 BD 公司所得，不产生委员会投资和非 BD 分配。
4. 三个样例均核对 Finance 现金流水只记一次，项目归因与 Archive 记录能还原上述结果。

以上是手算 fixture；金额只为验证口径，不是经济平衡建议。
