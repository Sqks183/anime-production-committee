## 已确认的美术要求

- 温暖、协调、可用于游戏界面的日式 16-bit 像素风插画。
- 不接受摄影、3D、普通矢量插画或明显风格冲突。
- 不再恢复旧版固定逻辑网格、24 色、禁抗锯齿等已取消要求。
- PNG；按用途保持正确宽高比，不拉伸。
- 文件名使用英文小写和下划线。

## 负责人交付内容

1. **逐图授权核查**：记录图像生成工具/服务的实际适用条款，确认商用、修改、分发、署名要求，以及是否允许将图片放入公开 GitHub 仓库。无法确认的部分明确标为阻塞，不推断授权。
2. **共享方式**：仅在授权和公开共享范围明确后，将获准图片放入 `apps/web/public/assets/` 对应目录。不得上传整个被忽略的 `.tools/`，不得使用临时 URL。
3. **素材目录更新**：在 `docs/ASSET_CATALOG.md` 中逐项更新来源、条款、尺寸、格式、文件路径、审核状态和授权状态；必要时更新 `docs/asset_prompts.json`。
4. **接入准备/接入**：若授权通过，与前端协商使用位置；接入时提供真实浏览器截图和验证结果。
5. **阻塞报告**：若原图不可共享或授权链无法确认，写明具体缺少什么证据、当前保留状态及可行替代方案。不得伪造许可结论。
